최강상규만들기 v0.4

ZIP 전체 압축 해제 → START_WINDOWS.bat 실행. Python 3.10 이상/tkinter 필요.
기존 자동 저장 파일을 이어 사용합니다. assets 폴더를 유지하세요.

[영구 연구: 각 0/5~5/5]
강화 속도: 3 → 2.5 → 2 → 1.5 → 1 → 0.5초
강화 비용: 단계마다 5%, 최대 25% 감소
해금 상규 구매 비용: 단계마다 5%, 최대 25% 할인 (100 G 단위 올림)
강화 성공률: 단계마다 +1%p, 최대 +5%p (전체 성공률 상한 100%)
+1 기본 구매/파괴 방지에는 상점 할인이 적용되지 않습니다.
연구 비용은 research_prices.csv 참조.
영구 연구는 자동 저장/새 게임에도 유지. 실험실 연구는 일반 모드에 반영되지 않음.
기존 저장은 연구 0단계로 호환됩니다.

[상점]
최초 +10 달성 시 해금. +10~+20 각각 발견한 단계만 이름/구매 해금.
기존 도감 발견 기록도 인정합니다.
상점 기본 가격은 판매가 1.5배를 100 G 단위 올림.
최대 할인에서도 구매가가 판매가보다 높습니다.
기본 +1 구매와 상점 구매는 0.5초 구매 대기를 공유합니다.

[파괴 방지]
+20 달성 시 해금. 현재 +20~+29 강화 화면에서 체크하여 사용합니다.
보관형 아이템이 아니라 강화 시 자동 구매·즉시 소모되는 1회 보호입니다.
시도당 가격: 최소 20,000,000 G 또는 현재 단계 판매가 75%(100 G 올림) 중 큰 금액.
성공/실패 모두 강화 비용과 보호 비용, 강화 재료를 소모합니다.
실패하면 대상 상규는 현재 단계 유지. 성공하면 정상적으로 1단계 상승.
체크를 유지하면 다음 강화에도 자동 적용됩니다. 자금 부족 시 시도 자체가 취소됩니다.
+16~+19에는 사용 불가. +30은 최종 단계로 강화 불가.

[기존 기능]
백과사전, 3종 목록 정렬, 기본 상규 시작 화면 유지.
Space 강화 / B 또는 한글 ㅠ +1 구매. Num Lock 처리 유지.
현재 +15까지 실패 시 1단계 하락, +16부터 파괴(보호 적용 제외).
현재 +20부터 강화 시 현재 단계보다 1 낮은 재료 필요.

검증: 38개 테스트 통과. Windows 실제 GUI/키 입력은 제작 환경에서 미검증.
연구 가격과 보호 비용은 프로토타입 초기 밸런스입니다.

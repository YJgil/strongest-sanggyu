최강상규만들기 v0.3

실행: ZIP 전체 압축 해제 후 START_WINDOWS.bat 실행.
Python 3.10 이상과 tkinter 필요. 실행에 외부 패키지 불필요.
assets 폴더를 이동하거나 삭제하지 마세요.

[새 기능]
- 기본 상규 시작 화면: 아무 키 또는 클릭으로 입장.
- 백과사전: 시대별 목차, 30개 개별 설명, 이미지, 가격/강화 정보.
  이전/다음 버튼 또는 좌우 화살표로 페이지 이동. 미발견 정보는 숨김.
- 보유 목록: 높은 등급순(기본), 낮은 등급순, 획득순.
  강화 및 구매 후에도 선택한 기준으로 즉시 재정렬.
- 상점: 실제 발견한 +10~+20 상규만 구입.
  가격은 판매가 × 1.5를 100 G 단위로 올림.
  +1 구매와 상점 구매는 0.5초 구매 대기를 공유.

[조작]
Space: 선택한 상규 강화. B 또는 한글 ㅠ: +1 상규 구매.
Num Lock이 켜진 Windows에서도 키 상태를 올바르게 처리합니다.
시작 화면 진입 키는 강화/구매에 사용되지 않습니다.
상점이 열려 있을 때는 게임 단축키를 차단합니다.

[진행]
기존 저장 자동 이어하기. 도감 발견 기록으로 상점이 자동 해금됩니다.
실험실은 임시 기록만 사용하며 일반 진행에 반영하지 않습니다.
강화 규칙/확률은 v0.2.2와 동일합니다.
현재 +15까지 실패 시 1단계 하락, +16부터 실패 시 파괴.
현재 +20부터 강화 시 현재 단계보다 1 낮은 재료 상규 소모.

[검증]
python -m unittest discover -v (이미지 테스트는 Pillow 필요).
Windows 실제 키 입력은 제작 환경에서 검증 불가.

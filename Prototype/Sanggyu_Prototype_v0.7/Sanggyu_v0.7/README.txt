최강상규만들기 v0.7

실행: 압축 전체 해제 후 START_GAME.vbs (콘솔 없음).
Python 3.10 이상, tkinter 필요. 실행 문제 확인은 START_DEBUG.bat.
기존 자동 저장 파일 그대로 사용. assets 폴더 유지.

[목표 강화 잠금]
강화 화면에서 목표 +1~+30 선택. 기본 +30.
목표 이상이면 Space/버튼/연속 강화 모두 차단. 목표를 높이면 해제.
전체 보유 상규에 공통 적용되며 설정 저장. 판매는 별도로 가능.
초월 +2 성공도 목표까지만 상승. 연속 강화도 목표에 도달한 즉시 중단.
강화 중에는 목표 변경 불가.

[단축키]
Space 강화 / B(ㅠ) +1 구매 / S(ㄴ) 판매.
+10 이상 판매 확인 유지. 판매 간격 최소0.5초.
구매/판매/강화는 연출 중 차단. 사냥 중인 상규는 판매/강화/재료 사용 불가.

[자동사냥]
1명 배치. 판매가의0.1%/분, 실제 활동60초마다 지급 (시간당6%).
같은 상규의 판매가만큼 벌려면 약16시간40분.
게임 실행 및 입장 중만 활동. 종료/절전 수입 없음.
분당 정산 대기시간과 누적액 표시. 소수점 수입 보존.
복귀/재접속 시 미정산액 및 남은 시간 보존. 무배치 중 정산시간은 정지.

[실패 규칙]
현재+1~+15: 실패하면1단계 하락 (최저+1).
현재+16: 실패 중10% 파괴,90% 하락.
이후 현재 단계마다 파괴 비중5%p 증가 → 현재+29는75% 파괴,25% 하락.
화면 성공/하락/파괴 확률은 각 시도 전체를 기준으로 합계100%.
예: +16→17, 연구없음: 성공65%,하락31.5%,파괴3.5%.
보호 사용 시 실패는 현재 단계 유지. 보호비/강화비/재료 소모 규칙 유지.

[유지 기능]
6종 영구 연구, 상점, 백과사전, 등급 정렬, 시작 화면.
성공 시 초월확률1~5%, 최대+2. 연속 강화 최대10회/2.5초.
연구/도감은 새 게임에 유지. 실험실 진행은 일반 진행과 분리.

[화면]
글자 최소 크기/보조글 대비 증가. 강화 영역 세로 스크롤.
시작 화면 타이틀/입장 버튼 강조. Windows 실제 화면은 제작 환경에서 미검증.



[v0.7 보스 원정]
상규 선택 → ⚔ 보스 원정 → 도전. 입장 조건 +3/+6/+10/+15/+20/+25/+30.
공격: 기력+1 / 방어: 피해80% 감소, 기력+1 / 필살기: 기력3으로 피해3배.
3턴마다 보스 강공격(피해2배) 예고. 회복은 원정당1회, 최대체력50%.
무료 입장, 원정 분신 전투로 보유 상규 손실 없음. 사냥 중인 상규는 복귀 필요.
보스별 첫 격파 보상 1회. 격파한 보스 재도전 없음.
창을 닫거나 재실행해도 전투 이어하기. ★ 업적 · 보상에서 업적8종 직접 수령.
새 게임에도 보스 격파/수령한 업적 유지, 진행 중인 전투 종료. 실험실은 별도 임시 원정.
이전 저장 최초 이관 시 같은 폴더에 save-pre-v0.7.json 백업.
최신 버전으로 플레이한 저장은 이전 버전에서 실행하지 마세요(원정 기록 누락 가능).

macOS: START_MAC.command 또는 python3 main.pyw. tkinter 필요.
검증: 회귀/원정 테스트64개 통과. macOS 실제 Tk 창에서 주요 흐름 확인.
Windows 실행기는 유지했으며 Windows 실제 화면은 미검증.

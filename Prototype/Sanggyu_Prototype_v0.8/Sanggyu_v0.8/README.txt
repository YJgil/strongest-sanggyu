최강상규만들기 v0.8 — 강화하고, 팔고, 다시 도전

[시작]
Windows: START_GAME.vbs. 오류 확인: START_DEBUG.bat.
macOS: START_MAC.command. Python 3.10+/Tk 8.6+ 자동 탐색.
실행 로그: ~/Library/Logs/StrongestSanggyu/launch.log
Python/tkinter 필요. assets 폴더를 함께 유지하세요.

[메인 플레이]
B(ㅠ)로 +1 구매 → Space 강화 → S(ㄴ)로 판매.
보유 목록의 판매가를 보고 목록 아래 큰 '상규 팔기' 버튼으로 판매합니다.
선택한 상규의 다음 등급 판매가도 안내합니다.
판매 버튼은 스크롤 없이 고정 표시. +10 이상 판매 확인, 0.5초 판매 간격.
강화 목표 도달 후에도 판매 가능. 사냥 중이면 복귀 후 판매.
강화 연출 중 구매/판매/강화 입력 차단.

[던전 — 보너스 골드]
던전 창에서 상규 선택 → '던전 입장 · 자동 전투'.
입장 조건 +3/+6/+10/+15/+20/+25/+30. 첫 격파 보상은 각 보스당 1회.
공격/방어/필살기/회복을 자동 선택하고 골드를 바로 지급합니다.
'강화·판매로 돌아가기'로 복귀하여 상규를 강화하거나 팔 수 있습니다.
보유 상규 손실 없음. 전투 후에도 판매 가능. 자동사냥 중인 상규는 복귀 후 입장.
돌아가거나 창을 닫으면 전투가 멈추고 저장됩니다. 다음 입장 시 이어하기.
돌아가서 출전 상규를 팔아도 입장 당시 분신으로 전투 이어하기 가능.
원하면 '직접 조작으로 전환': 강공격 전 방어, 기력3에서 필살기.

[저장 및 기존 기능]
v0.7 저장과 호환. 기존 버전 폴더는 보존됩니다.
자동 저장, 영구 연구, 도감, 상점, 자동사냥, 업적8종, 실험실 유지.
새 게임에도 도감/연구/보스 격파/수령 업적 유지. 진행 중인 전투는 종료.

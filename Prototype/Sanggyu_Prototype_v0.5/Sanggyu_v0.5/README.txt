최강상규만들기 v0.5

[콘솔 없이 실행]
ZIP 전체 압축 해제 후 START_GAME.vbs 더블클릭.
Python 3.10 이상 (pythonw 또는 pyw), tkinter 필요. 외부 패키지 불필요.
START_WINDOWS.bat도 새 실행기로 연결되지만 Windows 특성상 순간적으로 콘솔이 보일 수 있습니다.
완전히 콘솔 없이 시작하려면 START_GAME.vbs 또는 main.pyw를 사용하세요.
실행 오류 확인: START_DEBUG.bat. Windows가 VBS를 차단하면 main.pyw를 pythonw로 실행하세요.

[자동사냥]
자동사냥 메뉴에서 1명 배치/복귀. 배치 중 판매/강화/재료 사용 불가.
시간당 해당 상규 판매가의 2% 지급. 판매가만큼 회수하려면 50시간.
게임을 켜두고 입장한 동안만 수입 발생. 종료/컴퓨터 절전 시간은 수입 없음.
소수점 수입도 누적. 배치/누적 잔액은 저장. 복귀 시 행동 제한 즉시 해제.

[영구 연구 6종]
기존 4종: 강화 속도 3→0.5초, 강화 비용 최대25% 절감,
상점 최대25% 할인, 성공률 최대+5%p (총 확률100% 상한).
초월 강화: 5단계. 강화 성공 후 1~5% 확률로 +2 상승. 최종30 제한.
건너뛴 중간 단계도 도감/상점 해금 인정. 재료/비용은 시도 시작 단계 기준.
10회 연속 강화: 1단계 단일 해금. 가격은 +30 판매가의 2.5배.
해금 후 강화 화면의 전용 버튼 사용. 250ms마다 독립 시도, 최대10회/2.5초.
일반 속도 연구와 별개. 각 시도마다 비용/재료/선택한 보호 비용 지불.
재료는 사냥 중이 아닌 적합한 상규에서 자동 선택.
대상 파괴/30달성/자금·재료 부족이면 즉시 중단, 다른 상규로 이어가지 않음.
보호 체크 상태는 연속 강화 시작 시 고정하고 현재20 이상인 시도에만 적용.
연속 강화 중 다른 조작 금지. 종료하면 완료된 시도까지 저장됨.

[나머지 연구 후보: 미구현]
1. 사냥 숙련: 자동사냥 수입 단계당10% 증가, 최대50%.
2. 파견 확장: 1→2→3명. 추가 슬롯은 비싸게, 총 자동수입 제한 검토.
3. 실패 환급: 실패 시 강화비만 최대20% 반환. 보호비/재료 환급 제외.
4. 보호 계약: 파괴 방지 비용 최대15% 할인.
위 네 후보를 더하면 총10종. 아직 합의/밸런스 검토 전이므로 현재 구매 불가.

[저장/조작]
기존 저장 이어 사용. 새 연구는0단계, 사냥은미배치로 호환.
도감/영구연구는 새 게임에도 유지. 실험실은 일반 진행과 분리.
Space 강화, B/ㅠ +1구매. 구매0.5초 대기. NumLock 대응 유지.
성공률은 최종확률 (+연구보너스%p)로 표시.
상점은10달성 해금, 발견한10~20 구매. 파괴방지는20달성 해금.
보호비 최소2,000만G 또는 현재판매가75% 중 큰 금액. 성공해도 소모.
보호실패 시 현재단계 유지, 비용·재료 소모.

[검증]
46개 테스트 통과. Windows 실제 GUI/키 입력 및 VBS 실행은 제작 환경에서 미검증.

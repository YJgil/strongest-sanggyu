최강상규만들기 / 데스크톱 프로토타입 0.1

실행
1. ZIP을 폴더에 모두 압축 해제하세요.
2. Python 3.10 이상(Windows 기본 설치에 포함되는 tkinter 필요)이 설치되어 있어야 합니다.
3. START_WINDOWS.bat를 실행하세요. 또는 터미널에서 python main.pyw
별도 pip 패키지, 인터넷, 계정은 필요 없습니다.
이 파일은 독립 실행형 Windows EXE가 아닌 Python 데스크톱 프로그램입니다.

게임 규칙
- 초기 자본 50,000 G와 +1 애기 상규 1명.
- +1 상규 구매 200 G, 보유 한도 200명.
- 목록에서 강화할 상규를 선택한 후 강화 버튼을 누르세요.
- 현재 +1~+15에서 실패: 1단계 하락. +1은 그대로 유지.
  따라서 +15→+16 실패는 +14, +16→+17 실패는 파괴입니다.
- 현재 +16 이상에서 실패: 대상 상규 파괴.
- +20→+21부터 현재 단계보다 1 낮은 상규 1명이 추가 재료.
  +20→+21에는 +19, +29→+30에는 +28이 필요합니다.
- 재료는 성공/실패와 무관하게 소모됩니다. 강화 전에 재료 선택을 확인하세요.
- 확률은 매 시도 독립 추첨이며 누적 보정/천장은 없습니다.
- 비용: 100 × 1.38^(현재 단계-1), 10 G 단위 반올림.
- 판매가: 150 × 1.9^(현재 단계-1), 10 G 단위 반올림.
- 상규가 없고 자금이 200 G 미만이면 긴급 지원 2,000 G.
- 도감은 한 번 획득한 단계의 이름을 공개하며 파괴/판매 후에도 유지됩니다.
- 새 게임은 자금/보유/통계를 초기화하되 도감을 유지합니다.

실험실
일반 진행을 보존한 채 별도 임시 게임에서 10억 G로 시작합니다.
원하는 +1~+29 상규를 생성해 후반 재료와 연출을 테스트하세요.
실험실은 저장하지 않으며 일반 도감에도 반영하지 않습니다.

저장
Windows: %LOCALAPPDATA%\StrongestSanggyu\save.json
다른 OS: ~/.local/share/StrongestSanggyu/save.json
매 행동 후 저장. 강화 결과는 연출 전에 결정/저장되므로 창 종료로 되돌릴 수 없습니다.
동시에 여러 창을 실행하면 저장이 덮어써질 수 있으므로 한 창만 실행하세요.

검증과 제한
핵심 규칙 단위 테스트와 Python 구문 검사를 통과했습니다.
제작 환경에 그래픽 디스플레이가 없어 실제 Tk 창 및 Windows 실행은 검증하지 못했습니다.
프로토타입 확률/경제이며 +30의 평균 달성시간은 아직 조정하지 않았습니다.
후반 파괴와 재료 육성이 누적되므로 일반 모드 +30은 매우 오래 걸릴 수 있습니다.
외부 결제/현금 보상 기능이 없는 싱글플레이 게임입니다.

추가 아이디어 후보 (아직 미구현)
1. 묘비 도감: 파괴된 고강 상규의 이름/마지막 유언 기록.
2. 관측자 침식: +25부터 UI가 상규에게 존댓말, +29에서 역할 역전.
3. 강화 실패 방송: 단계별 가짜 뉴스 자막과 전 세계 반응.
4. 장비 칭호: 3대 500 / 중력 관리자 등 시각적 업적, 확률에는 영향 없음.
5. 인생 1회 파괴 방지권: 구매 전 성공 확률과 기대비용을 함께 재조정한 후 도입 검토.

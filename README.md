## 게임 소개

**애기 상규부터 +30 상규까지. 강화 버튼 하나로 시작하는 최강의 도전.**

상규를 구매하고 강화해 더 높은 단계에 도전하는 강화 중심 게임입니다. 성공하면 새로운 모습과 이름을 발견하고, 실패하면 하락과 파괴의 위험을 감수해야 합니다. 판매로 다음 도전의 자금을 마련하고, 영구 연구로 강화 효율을 높여 나갑니다.

| 핵심 시스템 | 플레이 방식 |
| :--- | :--- |
| ⚔️ 보스 원정 | 7단계 보스, 공격 예고를 읽고 공격·방어·필살기 선택 |
| 🏆 업적 8종 | 강화·도감·원정 목표를 달성하고 일회성 성장 보상 수령 |
| ⚡ 30단계 강화 | 단계마다 달라지는 이름과 전용 캐릭터 이미지 |
| 🎯 목표 강화 잠금 | 설정한 등급에 도달하면 강화 자동 중단 |
| 📖 백과사전 도감 | 발견한 상규의 이미지·설명·강화 정보를 수집 |
| 🛒 해금 상점 | +10 달성 후, 발견한 +10~+20 상규 구매 |
| 🧪 영구 연구 | 속도·비용·확률을 개선하고 초월·연속 강화 해금 |
| 💰 자동사냥 | 상규를 배치해 매분 보조 수입 획득 |
| 🛡️ 파괴 방지 | +20 달성 후 고강화 도전을 위한 보호 기능 해금 |
| 💾 자동 저장 | 돈·보유 상규·도감·연구를 이어서 플레이 |

## 시작하기

1. **Python 3.10 이상**을 설치합니다. `tkinter`가 포함된 환경이 필요합니다.
2. 게임 파일을 내려받아 압축을 모두 풀고 **`Prototype/Sanggyu_Prototype_v0.7/Sanggyu_v0.7`** 폴더를 엽니다.
3. **`START_GAME.vbs`**를 더블클릭합니다.
4. 시작 화면에서 **아무 키**를 눌러 입장합니다.

`assets` 폴더는 게임 파일과 함께 유지해 주세요. 실행 문제가 있다면 `START_DEBUG.bat`으로 오류를 확인할 수 있습니다. Windows 실행기를 제공하며, macOS에서는 `START_MAC.command` 또는 아래 명령으로 실행할 수 있습니다. Python에 `tkinter`가 설치되어 있어야 합니다. macOS 실행기는 Python 3.10+/Tk 8.6+ 환경을 자동 탐색합니다. 오류가 나면 터미널 창과 `~/Library/Logs/StrongestSanggyu/launch.log`에서 확인할 수 있습니다.

```sh
cd Prototype/Sanggyu_Prototype_v0.7/Sanggyu_v0.7
python3 main.pyw
```

## 조작법

| 입력 | 동작 |
| :---: | :--- |
| **Space** | 선택한 상규 강화 |
| **B** | +1 상규 구매 |
| **S** | 선택한 상규 판매 |
| **마우스** | 상규 선택, 상점·연구·도감 등 이용 |

구매와 판매에는 각각 최소 **0.5초 간격**이 적용됩니다. +10 이상 판매 시 확인 창이 표시되며, 강화 연출 중에는 구매·판매·강화 입력이 제한됩니다.

## 강화의 규칙

- **현재 +1~+15:** 실패 시 1단계 하락합니다. 최저 단계는 +1입니다.
- **현재 +16~+29:** 실패 시 하락 또는 파괴됩니다. 실패 중 파괴 비중은 +16에서 10%로 시작해 단계마다 5%p씩 증가하고, +29에서 75%가 됩니다.
- **현재 +20 이상:** 강화에 재료 상규가 필요하며 성공·실패 모두 재료가 소모됩니다.
- **파괴 방지 사용:** 실패해도 대상의 현재 단계를 유지합니다. 강화비·보호비·재료는 소모됩니다.
- **목표 잠금:** 선택한 목표 이상에서는 강화가 중단됩니다. 초월 강화도 목표를 넘지 않으며, 목표를 높이면 다시 강화할 수 있습니다.

> 예시: 연구가 없는 +16 → +17 시도는 **성공 65% · 하락 31.5% · 파괴 3.5%**입니다. 실패 중 파괴 비중과 실제 시도당 파괴 확률은 다릅니다.

## 성장 시스템

| 영구 연구 | 최대 효과 |
| :--- | :--- |
| 강화 속도 | 3초 → **0.5초** |
| 강화 비용 | **25% 감소** |
| 상점 구매 비용 | **25% 할인** |
| 강화 성공률 | **+5%p** |
| 초월 강화 | 성공 시 **최대 5% 확률로 +2 상승** |
| 10회 연속 강화 | **최대 10회 / 2.5초**, +30 판매가의 2.5배로 해금 |

연속 강화는 목표 도달·파괴·자금 부족·재료 부족 시 중단됩니다. 영구 연구와 발견 도감은 새 게임에서도 유지됩니다.

자동사냥은 **1명**을 배치하며, 해당 상규 판매가의 **0.1%를 활동 60초마다 지급**합니다. 사냥 중인 상규는 판매·강화·재료 사용이 불가능합니다. 수입은 게임에 입장해 실행 중일 때만 발생하며, 종료·절전 중에는 발생하지 않습니다.

## 보스 원정 · v0.7

강화한 상규를 선택하고 **⚔ 보스 원정**을 누르세요. +3부터 입장하며 각 보스를 순서대로 격파합니다.

| 보스 | 입장 조건 |
| :--- | :---: |
| 급식실의 지배자 | +3 |
| 헬스장 문지기 | +6 |
| 단백질 골렘 | +10 |
| 중력 집행관 | +15 |
| 블랙홀 관장 | +20 |
| 인과율 감사관 | +25 |
| 밸런스 패치의 신 | +30 |

- **공격:** 기본 피해를 주고 기력 +1, 최대 3.
- **방어:** 이번 턴에 받는 피해 80% 감소, 기력 +1. 보스는 **3턴마다 2배 강공격**을 예고합니다.
- **필살기:** 기력 3을 소비하여 기본 공격의 3배 피해.
- **회복:** 원정당 1회, 최대 체력의 50% 회복. 사용한 턴에도 보스가 공격합니다.
- 입장 시 등급을 복사한 **원정 분신**으로 싸웁니다. 무료 입장이며 패배·포기로 보유 상규나 자금을 잃지 않습니다. 자동사냥 중인 상규는 복귀 후 입장하세요.
- 첫 격파 보상은 각 보스당 1회, `max(3,000 G, 입장 조건 등급 판매가 × 2)`입니다. 격파한 보스 재도전은 제공하지 않습니다.
- 전투는 행동마다 자동 저장됩니다. 창을 닫거나 게임을 재실행해도 이어집니다. 강화·도감·원정 업적 **8종**은 **★ 업적 · 보상** 창에서 직접 수령합니다.
- 새 게임에서도 보스 격파와 수령한 업적 기록을 유지하여 중복 보상을 막습니다. 진행 중인 전투와 강화 시도/성공 횟수는 초기화됩니다. 실험실은 별도 임시 원정입니다.

## 저장 데이터

같은 컴퓨터에서는 새 버전을 실행해도 기존 저장을 이어서 사용합니다.

```text
%LOCALAPPDATA%\StrongestSanggyu\save.json
```

macOS 기본 저장 위치는 `~/.local/share/StrongestSanggyu/save.json`입니다. v0.7에서 플레이한 뒤 이전 버전으로 실행하면 원정 기록이 저장에서 누락될 수 있으므로 최신 버전을 사용하세요.

다른 컴퓨터로 이동할 때는 게임을 종료한 뒤 위 파일을 같은 경로에 복사하세요. 기존 저장이 있다면 덮어쓰기 전에 백업해 주세요.
